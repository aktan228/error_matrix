# Матрица ошибок — вариант №14

Учебная работа по оценке модели, которая определяет плагиат в студенческих работах.

В Jupyter Notebook представлены:
- исходная матрица ошибок и объяснение TP, FN, FP, TN;
- расчёт accuracy, precision, recall, specificity и F1;
- сравнение с моделью, которая всегда отвечает «нет»;
- анализ стоимости ошибок;
- новая матрица после снижения порога и сравнение метрик.

Использованы Python, NumPy и Matplotlib. Выполнены пункты 1–6 основного уровня.

## Запуск

Откройте файл `.ipynb` в Google Colab или Jupyter Notebook и выполните все ячейки.
